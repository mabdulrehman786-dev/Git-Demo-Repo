# 📖 Overview

**Git-Demo-Repo** is a simple demonstration repository created to help beginners understand the fundamentals of **Git** and **GitHub** through practical examples.

This repository serves as a learning playground where users can practice Git commands, understand version control concepts, and become familiar with GitHub workflows without worrying about making mistakes.

Whether you are a student, a beginner developer, or someone learning collaborative software development, this repository provides a solid starting point.

# 📚 Basic Git Commands

## Initialize Git

```bash
git init
```

---

## Clone Repository

```bash
git clone <repository-url>
```

---

## Check Status

```bash
git status
```

---

## Add Files

```bash
git add .
```

or

```bash
git add filename
```

---

## Commit Changes

```bash
git commit -m "Initial Commit"
```

---

## View Commit History

```bash
git log
```

---

## Push Changes

```bash
git push origin main
```

---

## Pull Latest Changes

```bash
git pull origin main
```

---

## Create New Branch

```bash
git branch feature-branch
```

---

## Switch Branch

```bash
git checkout feature-branch
```

or

```bash
git switch feature-branch
```

---

## Merge Branch

```bash
git merge feature-branch
```

# 📖 Common Git Commands

| Command | Description |
|----------|-------------|
| `git init` | Initialize repository |
| `git clone` | Clone repository |
| `git status` | Show current status |
| `git add .` | Stage all files |
| `git commit` | Save changes |
| `git push` | Upload changes |
| `git pull` | Download changes |
| `git fetch` | Fetch remote updates |
| `git log` | View commit history |
| `git diff` | Show differences |
| `git branch` | List branches |
| `git checkout` | Switch branch |
| `git switch` | Switch branch (new command) |
| `git merge` | Merge branches |
| `git stash` | Save temporary changes |
| `git remote -v` | Show remote URLs |

# ❓ Frequently Asked Questions

### What is Git?

Git is a distributed version control system used to track changes in source code and collaborate efficiently with other developers.

### What is GitHub?

GitHub is a cloud-based platform that hosts Git repositories and enables collaboration through features like Pull Requests, Issues, and Actions.

### Do I need GitHub to use Git?

No. Git works locally on your computer. GitHub is an online hosting service for Git repositories.
